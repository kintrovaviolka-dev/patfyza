## 2024-05-28 - Index-Based Data Mapping
**Learning:** Unlike some static applications that rely on exact string matching for ID generation or data mapping, this application uses array index-based mapping to link topics (e.g., `RAW_QUESTIONS_SPECIAL_2` in `data_core.js`) to their detailed content objects (e.g., `SPECIAL_2_DETAILS` in `data_special2.js`). The IDs are generated as `spec-2-${idx + 1}`.
**Action:** When updating content strings in arrays like `RAW_QUESTIONS_SPECIAL_1` or `RAW_QUESTIONS_SPECIAL_2`, there is no need to worry about breaking the connection to the detailed content objects in `data_special1.js` or `data_special2.js` as long as the array order and length remain unchanged.
