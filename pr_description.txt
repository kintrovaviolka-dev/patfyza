🎯 What: Replaced direct, unsanitized assignment to `innerHTML` when generating EKG preset buttons with a secure approach.

⚠️ Risk: User input within `p.name` or `hrText` could potentially contain malicious HTML or scripts. If injected into the page via `innerHTML` without sanitization, this could lead to Cross-Site Scripting (XSS) attacks.

🛡️ Solution: Implemented a secure fallback mechanism. The code now first attempts to use `DOMPurify` to sanitize the HTML string before assignment. If `DOMPurify` is unavailable, it gracefully degrades to dynamically creating DOM elements (`createElement`) and safely assigning text using `textContent`, which intrinsically escapes HTML entities.
