🎯 **What:** Fixed an XSS vulnerability in `ekg_sim.js` where `dialogMarkup` was injected directly into the DOM using `insertAdjacentHTML` without sanitization.
⚠️ **Risk:** If any interpolated variables in the `dialogMarkup` template (such as `preset.name` or `simState.score`) were manipulated by an attacker or sourced from unvalidated inputs, it could lead to arbitrary JavaScript execution in the context of the user's browser, potentially compromising session data or user actions.
🛡️ **Solution:** Wrapped `dialogMarkup` in `DOMPurify.sanitize()` before injecting it via `insertAdjacentHTML`. Implemented a fail-secure fallback replacing the modal with an error message if DOMPurify fails to load, consistent with other security fixes in the codebase.
